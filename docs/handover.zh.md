# 藤飞壁球俱乐部官网 — 交接清单

俱乐部独立运营 flysquash.com 所需的全部内容。

网站背后有**三个相互独立的账号**，需要分别完成交接。

| # | 项目 | 服务商 | 作用 | 费用 |
|---|---|---|---|---|
| 1 | 源代码 | GitHub | 存放网站文件及修改历史 | 免费 |
| 2 | 网站托管 | Vercel | 构建网站并向访客提供访问 | 免费套餐即可 |
| 3 | 域名 | GoDaddy | 持有 `flysquash.com` | 约 20 美元/年（续费） |

> **开始之前：** 请先准备一个**俱乐部公用邮箱**（例如 `it@flysquash.com` 或俱乐部现有
> 管理邮箱），**不要**使用某位员工的个人邮箱——员工离职后账号会难以找回。
> 三个账号都应注册在这同一个邮箱下。

## 一、GitHub —— 源代码

**当前状态：** 仓库 `ckttam/fsc-website`，归属于个人账号。

**建议：** 为俱乐部创建一个 GitHub **组织（Organization）**（例如 `fly-squash-club`），
并把仓库转移进去。组织不会因人员变动而失效，个人账号则会。

**操作步骤**
1. 俱乐部用公用邮箱注册 GitHub 账号，然后创建组织。
2. 当前所有者：仓库 → **Settings** → **General** → **Danger Zone** →
   **Transfer ownership**，填写俱乐部组织名。
3. 俱乐部在邮件中确认接收。
4. 在组织中设置**至少两位** Owner（所有者），避免单点依赖。
5. 确认仓库为 **Private（私有）**，除非确实希望公开。

**检查清单**
- [ ] 已用公用邮箱注册 GitHub 账号
- [ ] 已创建组织
- [ ] 仓库已转移并确认接收
- [ ] 至少两人拥有所有者权限
- [ ] 转移后已重新连接 Vercel（见第二节）

## 二、Vercel —— 网站托管

**当前状态：** 项目 `fsc-dynamic`，归属于个人 Vercel 账号。

Vercel 会在代码更新时自动构建网站，并在全球范围内提供访问。本网站用免费（Hobby）套餐
即可满足需求。需注意：Vercel 免费套餐面向非商业用途，企业使用应选择 Pro 套餐
（约 20 美元/月），具体以 Vercel 最新条款为准。

**两种方案：**

**方案 A —— 转移现有项目**（保留部署历史）
1. 俱乐部用公用邮箱注册 Vercel 账号，建议使用 GitHub 账号登录。
2. 当前所有者：Vercel 控制台 → 项目 `fsc-dynamic` → **Settings** → **Transfer** →
   选择俱乐部账号／团队。
3. 俱乐部确认接收。域名会随项目一并转移。

**方案 B —— 重新创建**（更简单，但会丢失历史记录）
1. 俱乐部注册 Vercel 账号，点击 **Add New → Project**。
2. 从 GitHub 导入 `fsc-website` 仓库。
3. 构建配置已写在仓库的 `vercel.json` 中——框架 Vite、构建命令 `npm run build`、
   输出目录 `dist`。网站代码位于仓库根目录，Root Directory 保持默认即可。
4. 添加域名 `flysquash.com` 和 `www.flysquash.com`。
5. **确认新项目能正常访问后**，再删除旧项目。

**强烈建议在此步骤同时完成：** 将项目与 GitHub 仓库连接
（Project → Settings → **Git**）。连接后，只要 GitHub 上的内容有更新，网站就会自动
重新发布——这正是让同事**只用浏览器**就能更新网站、无需电脑环境或开发人员的关键。
如果不连接，每次发布都需要有人在装有 Vercel 命令行工具的电脑上运行 `./deploy.sh`。

**检查清单**
- [ ] 已用公用邮箱注册 Vercel 账号
- [ ] 项目已转移（或重建并验证无误）
- [ ] 已连接 GitHub 仓库，实现自动发布
- [ ] `flysquash.com` 与 `www.flysquash.com` 均可正常打开
- [ ] 两个网址的 HTTPS 安全锁均正常

## 三、GoDaddy —— 域名

**当前状态：** `flysquash.com` 注册在 GoDaddy。

这是**最重要的一项资产**——一旦域名过期或丢失，网站地址将无法访问，并可能被他人抢注。

**操作步骤**
1. 俱乐部用公用邮箱注册 GoDaddy 账号。
2. 使用 GoDaddy 的 **Account Change（账号变更）** 功能转移域名。
   在同一注册商（GoDaddy）的不同账号之间转移是**即时且免费**的，
   而转移到其他注册商则需要数天并产生费用。
   路径：GoDaddy → **My Products** → 选择域名 → **Account Change**，
   填写俱乐部的 GoDaddy 账号邮箱。
3. 俱乐部确认接收。
4. **务必开启自动续费**，并绑定一张不会过期的付款方式。
5. 确认 DNS 记录仍指向 Vercel：

| 类型 | 主机记录 | 记录值 |
|---|---|---|
| A | `@` | `76.76.21.21` |
| CNAME | `www` | `cname.vercel-dns.com` |

**检查清单**
- [ ] 已用公用邮箱注册 GoDaddy 账号
- [ ] 域名已转入该账号
- [ ] **已开启自动续费**，付款方式有效
- [ ] 域名所有者信息填写为俱乐部，而非个人
- [ ] DNS 记录已按上表核对
- [ ] 域名到期日已记入俱乐部日程

## 四、建议的操作顺序

请按以下顺序操作，避免网站中断：

1. 用公用邮箱创建三个账号（GitHub、Vercel、GoDaddy）
2. 先转移 **GitHub**
3. 再转移 **Vercel**，并重新连接已转移的仓库
4. 确认 flysquash.com 正常访问——**然后再动 DNS**
5. 最后转移 **GoDaddy** 域名（DNS 记录不变，全程网站不会中断）
6. 开启所有账号的自动续费
7. 确认无误后，再移除原所有者的权限
