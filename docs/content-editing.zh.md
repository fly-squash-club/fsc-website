# 藤飞壁球俱乐部官网 — 内容编辑指南

**适用对象：** 需要修改 flysquash.com 上的文字、图片、教练、课程或新闻的俱乐部同事。
**无需任何编程基础。**

> **最重要的一条规则：** 网站是中英双语的。几乎每一处修改都需要做**两次**——
> 中文文件改一次，英文文件改一次。如果只改其中一个，另一种语言仍会显示旧内容。

---

## 一、编辑的基本流程

网站的所有内容都以文本文件的形式保存在 GitHub 上。你编辑文件、保存（称为"提交"），
网站会在大约一分钟内自动重新生成并上线。

网站没有单独的后台登录页面——**GitHub 就是后台。**

**每次修改的固定步骤：**

1. 打开代码仓库：`https://github.com/<账号>/fsc-website`
2. 点击进入需要修改的文件（下文会列出具体路径）。
3. 点击右上角的**铅笔图标**（✏️ Edit this file）。
4. 修改内容。
5. 向下滚动，简单写一句本次改了什么，点击 **Commit changes**（提交更改）。
6. 等待约 1 分钟，刷新 flysquash.com 查看效果。

如果出现问题，请看**第七节：如何撤销**——在这里所做的任何操作都是可以恢复的。

## 二、修改现有文字

网站上的所有文案只存在于两个文件中：

| 语言 | 文件路径 |
|---|---|
| 中文 | `src/locales/zh.json` |
| 英文 | `src/locales/en.json` |

两个文件的**结构完全相同**——相同的标签、相同的顺序。在两个文件中找到同一个位置，
修改冒号右侧的文字即可。

只修改**引号之间**的文字。例如在 `zh.json` 中修改课程介绍：

```
"personal": {
  "title": "私教课",
  "text": "针对个人技术、体能水平与竞技目标量身定制的一对一指导。"
}
```

你可以修改 `私教课` 和 `text` 后面的句子。**请勿**修改 `"personal"`、`"title"`、
`"text"` ——这些是网站用来定位内容的标签。

### 四条格式规则（重要）

这类文件的格式称为 JSON，对标点符号要求非常严格：

1. 所有文字必须包在**英文双引号**中：`"像这样"`
2. 每个区块中除最后一行外，每行结尾都要有**英文逗号**
3. 不要删除 `{`、`}`、`[`、`]` 这些符号
4. 文字内部如需引号，请使用中文引号「」或单引号——多余的 `"` 会导致页面出错

**注意：必须使用英文半角的引号和逗号**（`"` 和 `,`），中文全角的 `＂` 和 `，` 会报错。

如果违反了以上规则，网站构建会失败，**线上网站会继续显示修改前的版本**（不会变成空白页）。
GitHub 上会显示一个红色的 ✗。处理方法见第七节。

## 三、发布一条新闻

新闻分为两部分：首页上的**新闻卡片**，以及可选的**新闻详情页**。

### 3a. 卡片文字

在 `src/locales/zh.json` 和 `en.json` 中找到 `"news"` → `"list"` 部分，
复制一个已有的条目并修改内容：

```
"tournament": {
  "tag": "赛事",
  "title": "2026 上海女子春季公开赛",
  "body": "显示在首页卡片上的简短摘要。"
}
```

标签名（上例中的 `"tournament"`）在中英文两个文件中必须保持一致。

### 3b. 卡片图片

把图片放入 `public/` 文件夹（见第五节），然后在 `src/sections/News.vue`
文件顶部的列表中引用：

```js
const newsItems = [
  { id: 'camp', cover: '/news-camp.jpg', slug: 'camp-2026', extras: [] },
  ...
]
```

- `id` —— 必须与语言文件中的标签一致（如上文的 `"tournament"`）
- `cover` —— 卡片主图
- `extras` —— 可选，额外的图片，会显示为小缩略图
- `slug` —— **仅当**这条新闻有独立详情页时才需要填写（见下文）

### 3c. 新闻详情页（可选）

只有部分新闻需要独立的详情页。详情页内容存放在
`src/content/newsArticles.js`，该文件顶部写有完整的操作说明。

简单来说：复制整段 `'camp-2026': { ... }`，改一个新名字（小写英文、用连字符分隔、
不要空格，例如 `'winter-camp-2027'`），然后修改里面的 `en` 和 `zh` 内容。
最后把这个名字填入 `News.vue` 中对应卡片的 `slug`，卡片就会链接到详情页。

正文由以下几种"内容块"自上而下组成：

```js
{ type: 'lead',       text: '开头的大号段落' }
{ type: 'heading',    text: '章节标题' }
{ type: 'subheading', text: '小标题' }
{ type: 'paragraph',  text: '普通段落' }
{ type: 'list',       items: ['第一点', '第二点'] }
{ type: 'image',      src: '/news-photo.jpg', alt: '图片说明' }
{ type: 'divider' }
```

## 四、新增或删除教练

教练以海报图片的形式展示。每位教练需要**三样东西**：

**1. 海报图片** —— 放入 `public/`，命名为 `coach-<名字>.jpg`
（尺寸要求见第五节，海报原图通常很大，必须先压缩）。

**2. 在 `src/sections/Coaches.vue` 顶部的列表中新增一行：**

```js
{ id: 'ivan', zh: '/coach-ivan.jpg', en: '/coach-ivan.jpg' },
```

- `id` —— 简短的英文代号，小写、无空格
- `zh` / `en` —— 各语言下显示的海报。如果目前只有中文海报，两个都填同一个文件
  （如上例）。将来做好英文海报后，把 `en` 改成英文海报即可。
- 列表的顺序就是网站上的显示顺序。

**3. 姓名和头衔** —— 在 `zh.json` 和 `en.json` 的 `"coaches"` → `"list"` 中添加：

```
"ivan": { "name": "Ivan Yuen", "role": "S级顾问" }
```

这里的标签必须与 `Coaches.vue` 中的 `id` 完全一致。

`"experience"` 为选填项——如果填写（例如 `"15+ 年"`），鼠标悬停在照片上时会显示。
没有确切年限就不填。

**删除教练：** 删掉 `Coaches.vue` 中对应的那一行即可。语言文件中的姓名可以保留，
不会显示出来。

## 五、图片

所有图片都放在 `public/` 文件夹中。引用时在文件名前加 `/`，
例如 `public/coach-ali.jpg` 写作 `/coach-ali.jpg`。

**只换图、不改代码的方法：** 上传一个**文件名完全相同**的新图片即可。
在 GitHub 中：进入 `public` 文件夹 → **Add file** → **Upload files**。

### 图片大小很重要，请务必阅读

手机拍摄或设计师提供的原图通常有 2–5 MB，会让网站变得很慢，尤其是用手机流量访问时。
**上传前请先压缩图片。**

目标：**小于 400 KB**，宽度不超过 **1200 像素**，保存为 **JPG** 格式。

Mac 上最快的方法是用系统自带的"预览"App：
*工具 → 调整大小*（宽度设为 1200），然后 *文件 → 导出*，选择 JPEG，品质约 80%。

一个简单的判断标准：**文件超过 1 MB 就是太大了。**

### 命名规范

使用小写英文字母和连字符，文件名中不要有空格或中文：

- 正确：`coach-ali.jpg`、`news-camp-2027.jpg`
- 错误：`教练 Ali.png`、`Coach Ali (最终版).PNG`

## 六、请勿修改的文件

除非有开发人员协助，否则请不要改动以下内容：

- 任何 `.css` 结尾的文件（网站视觉设计）
- `src/Layout.vue`、`router.js`、`main.js`、`meta.js`（网站结构）
- `dist/` 文件夹（自动生成）
- `node_modules/` 中的任何内容

## 七、如何撤销

**你的任何操作都不会对网站造成不可挽回的损坏。** 每一次修改都有完整的历史记录，
并且只有构建成功，线上网站才会更新。

**如果构建失败**（GitHub 上你的修改旁边会出现红色 ✗）：
线上网站会继续显示修改前的版本。找到问题——通常是少了逗号或引号——改正后重新提交即可。

**撤销一个已经生效的修改：**

1. 在 GitHub 上进入 **Commits**（提交记录）列表
2. 找到对应的修改，点击 **`...`** 菜单 → **Revert**（撤销）
3. 确认——系统会生成一次新的"撤销"提交，网站随之更新

**紧急情况下整站回滚：** 见技术文档的"回滚"章节，或联系 Vercel 账号管理人。
